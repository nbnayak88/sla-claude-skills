# SuccessLabs Academy - Sector Transformation Skills

Claude skills that analyze a business transformation case study for any of the 11 GICS sectors, run a Fit-Gap for any SAP or non-SAP solution, and plan implementation with SAP Activate.

| Skill | Purpose |
|---|---|
| `sl-sector-transformation-orchestrator` | Master workflow: analyze > calibrate > Fit-Gap > Activate plan > package |
| `sl-case-analyzer` | Independent case analysis into a Case Analysis Pack with evidence-tagged requirements |
| `sl-gics-sector-profiles` | Starting profiles for the 11 GICS sectors (Energy calibrated on OmniVerse) |
| `sl-solution-fitgap` | Product-agnostic Fit-Gap with clean-core resolution rules |
| `sl-activate-implementation` | SAP Activate Discover-Run plan, gates, deliverables, 90-day wave |

The SuccessLabs SAP Activate ECP Payroll Skill Catalog is a separate asset and is not modified by these skills.

Approved By: SuccessLabs Academy Board Members. Case studies referenced are fictional learning cases.
