## Phase checklists (short)
**Explore exit:** requirements baselined; every gap has an agreed resolution; integration and data designs approved; test scenarios traced; safety/regulatory requirements owned.
**Realize exit:** UAT passed against acceptance criteria; open defects within agreed thresholds; migration reconciliations signed; security tests passed; training delivered; rollback tested.
**Deploy exit:** cutover rehearsed at least once; go/no-go approved; support owners named; hypercare exit criteria defined.
**Run:** benefits baselined and owner-accepted before claims; Finance validation.

## 90-day Wave 0
Days 1-30 charter, baselines, owners, environments. Days 31-60 fit-to-standard, backlog, integration/data design. Days 61-90 readiness decision, first build sprint plan, change capacity assessment.
