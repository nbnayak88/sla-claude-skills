# CAP Templates

## Requirement record
| Field | Entry |
|---|---|
| ID | REQ-<DOMAIN>-<nn> (e.g. REQ-AST-03) |
| Statement | "The solution shall ..." one testable sentence |
| Type | Functional / Non-functional / Data / Integration / Security / Compliance / Adoption |
| Priority | Must / Should / Could / Won't (this release) |
| Source | Case section + layer (e.g. Master 09-12, Phase C) |
| Evidence tag | Fact / Assumption / Hypothesis / Insight / Decision |
| Stakeholder | Owner role |
| Value link | KPI or benefit ID |
| Constraint link | Safety / regulatory / security item |
| Acceptance criterion | How we will know it is met |

## Validation backlog record
| Item | Question to resolve | Accountable reviewer | Needed by gate | Status |
|---|---|---|---|---|

## Evidence tags
- **Fact** stated input of the case. **Assumption** needed but unconfirmed. **Hypothesis** testable causal claim. **Insight** analyst inference. **Decision** approved choice (rare in learning cases).

## Domain codes (extend per sector)
AST asset, WRK workforce, CUS customer, FIN finance, PRC procurement, SCM supply chain, DAT data, INT integration, SEC security, ESG sustainability/regulatory, ANL analytics/AI, CHG change/adoption, INF infrastructure.
